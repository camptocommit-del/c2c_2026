Draft lottery

A draft order the commissioner can't steer, and that you can check yourself in about a minute.

Why this can't be rigged

The names get locked before anything random happens. Locking the list turns it into a long code — a fingerprint of those exact 12 names. Change one letter afterward and the fingerprint comes out completely different. So the roster you were shown is the roster that got used.

The randomness comes from outside the league. Ahead of the draw, the commissioner names a number that doesn't exist yet and that none of us can nudge: where the S&P 500 closes on a stated day. He can't pick a friendly one, because nobody knows it yet. He can't quietly try again, because he already told you which day counts.

The math gives everyone the same answer. The fingerprint and that closing number get scrambled together into an order. There's no dice roll and no button that shakes out something different on the second press — put the same two things in and this page produces the same 12 names in the same order, on anyone's phone.

So here's your check: take the result he posts, paste it into the box at the bottom of this page, and your own browser rebuilds the board from scratch. Match means it's real. If a name was swapped or the number was fudged, it won't match, and the page will say so.

1

Lock the roster

One manager per line. Locking produces a fingerprint of the list — post it to the league chat now, before the seed exists. Any later edit to the names produces a different fingerprint, so nobody can quietly swap a name in after the fact.

Roster fingerprint (SHA-256)

2

Name the seed before it happens

Announce a public number that does not exist yet and that none of you can influence. Pin down the exact format at the same time — every manager has to type the same characters or the shuffle lands somewhere else.

Write the closing level as plain digits with two decimals and no comma — 6412.83, not 6,412.83. Capitalization and extra spaces are ignored; a stray comma is not.

3

Run the draw

The fingerprint and the seed are hashed together into a shuffle. Same roster plus same seed always yields the same board, on any device, for anyone who opens this page.
